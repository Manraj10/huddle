## In one sentence

Huddle is a server-authoritative party-game engine that sends every player a different view of the same room, turning the room itself into the mechanic.

## Demo flow

1. Publish a public link and join three or more phones
2. Start with Flash to prove the shared clock is real
3. Move to Blindside to show hidden information and the laugh factor
4. Show seat placement and explain the meaning of angle-based targeting
5. Close with: “One link. No install. On whatever is already in your pocket.”

## Product framing

The project is not a single mini-game. It is an engine for party games that only function in a room with people in it. The server owns truth, the client renders views, and each player sees a different slice of the same shared state. That is the technical and emotional difference between a generic online toy and a social room game.
